Criando Páginas — Templates e Padrões

Template Básico

Toda página do dashboard segue este padrão:

// app/(dashboard)/[nome]/page.tsx
import { PageContainer } from "@/components/layout/page-container";
import { PageHeader } from "@/components/custom";

export default function NomePage() {
  return (
    <PageContainer>
      <PageHeader
        title="Título da Página"
        description="Descrição opcional"
      />
      {/* Conteúdo */}
    </PageContainer>
  );
}

Template com Stat Cards + Tabela

import { PageContainer } from "@/components/layout/page-container";
import { PageHeader, StatCard, DataTable, FilterBar } from "@/components/custom";
import { Card } from "@/components/ui";

export default function VendasPage() {
  return (
    <PageContainer>
      <PageHeader title="Vendas" description="Gerencie seus pedidos" />

      {/* Cards de métricas — sempre 2x2 mobile, 4 colunas desktop */}
      <div className="grid grid-cols-2 md:grid-cols-4 gap-3 mb-6">
        <StatCard title="Total" value="R$ 10.000" />
        <StatCard title="Pedidos" value="142" />
        <StatCard title="Ticket Médio" value="R$ 70" />
        <StatCard title="Conversão" value="3.2%" />
      </div>

      {/* Filtros + Tabela */}
      <Card>
        <FilterBar filters={[]} onFilterChange={() => {}} />
        <DataTable columns={[]} data={[]} />
      </Card>
    </PageContainer>
  );
}

Template Mobile (com MobilePageContainer)

Para páginas que precisam de layout mobile específico:

"use client";
import { useIsMobile } from "@/components/ui/use-mobile";
import { PageContainer } from "@/components/layout/page-container";
import { MobilePageContainer } from "@/components/layout/mobile-page-container";

export default function MinhaPage() {
  const isMobile = useIsMobile();

  if (isMobile) {
    return (
      <MobilePageContainer title="Título" subtitle="Subtítulo">
        {/* Versão mobile */}
      </MobilePageContainer>
    );
  }

  return (
    <PageContainer>
      {/* Versão desktop */}
    </PageContainer>
  );
}

Páginas complexas → components/pages/

Se a página tem muita lógica, extrair conteúdo para components/pages/:

// app/(dashboard)/vendas/pedidos/page.tsx
import VendasPedidosPage from "@/components/pages/vendas-pedidos";
export default function Page() {
  return <VendasPedidosPage />;
}

Regras

  • NUNCA crie layout.tsx dentro de subpastas do dashboard
  • NUNCA importe ou renderize SidebarMenu, TopBar ou MobileTabBar nas páginas
  • Sempre use PageContainer (desktop) ou MobilePageContainer (mobile)
  • Use "use client" apenas quando a página precisa de hooks ou estado
  • Dados vêm de hooks em hooks/ que consomem services em services/

Componentes disponíveis para páginas

Componente Import Uso
PageContainer @/components/layout/page-container Wrapper de toda página desktop
MobilePageContainer @/components/layout/mobile-page-container Wrapper mobile com topbar

DataTable @/components/custom Tabela com ordenação e paginação
