Retrilhar - Painel Administrativo

Stack

  • Next.js 16 (App Router) · React 19 · Tailwind CSS 4 · shadcn/ui
  • Ícones: HugeIcons (CDN font) via
  • Gráficos: Chart.js · Animações: Motion · Tabelas: TanStack Table
  • Testes: Vitest + Playwright · Docs: Storybook 10

Estrutura

app/(dashboard)/layout.tsx    ← Layout ÚNICO (sidebar + topbar + tabbar)
app/(dashboard)/[pagina]/     ← Páginas do dashboard
components/ui/                ← shadcn/ui (NÃO editar manualmente)
components/custom/            ← Componentes do projeto
components/layout/            ← PageContainer, MobilePageContainer
components/pages/             ← Conteúdo de páginas complexas
components/dashboard/widgets/ ← Widgets do dashboard
environments/[perfil]/        ← Menu e dashboard por perfil
hooks/                        ← Hooks com dados mock
mocks/                        ← Dados mock
services/                     ← Camada de API
types/                        ← TypeScript types

Comandos

npm run dev          # Dev server (turbopack)
npm run build        # Build de produção
npm run storybook    # Storybook na porta 6006

Regras Críticas — NUNCA faça

  1. NUNCA crie sidebar, topbar ou tabbar fora de app/(dashboard)/layout.tsx
  2. NUNCA use SVG inline ou CSS para ícones. Use
  3. NUNCA importe ícones de lucide-react em componentes custom. Lucide é só para dentro de components/ui/
  4. NUNCA use valores hex/rgb hardcoded. Use CSS variables (var(--brand-500)) ou classes Tailwind (text-brand-500)
  5. NUNCA injete CSS inline com style={{}} exceto para Chart.js ou transforms dinâmicos
  6. NUNCA recrie um componente que já existe em components/custom/ ou components/ui/
  7. NUNCA crie novo layout.tsx dentro de páginas do dashboard
  8. NUNCA importe componentes diretamente. Use barrel exports: @/components/ui, @/components/custom
  9. NUNCA use position: fixed para layout de página (o grid cuida disso)
  10. NUNCA use font-weight: 600 ou 700. O projeto usa 400 para tudo (override no globals.css)

SEMPRE faça

  • Toda página nova: app/(dashboard)/[nome]/page.tsx usando
  • Imports de UI: import { Button, Card } from "@/components/ui"
  • Imports custom: import { PageHeader, StatCard } from "@/components/custom"
  • Imports de ícone: import { Icon } from "@/components/ui/icon"
  • Cores: classes Tailwind (bg-brand-500, text-error-600, bg-success-50)
  • Antes de criar componente: verificar se já existe em components/custom/index.ts
