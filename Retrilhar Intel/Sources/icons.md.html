Regras de Ícones

O projeto usa DOIS sistemas de ícones. Cada um tem seu lugar.

HugeIcons — Ícones da aplicação

Usados em TODOS os componentes custom, páginas, widgets, sidebar, topbar, etc.

// ✅ CORRETO — Sempre assim
import { Icon } from "@/components/ui/icon";

<Icon name="search-01" size={20} className="text-slate-500" />
<Icon name="calendar-03" size={16} className="text-brand-400" />
<Icon name="shopping-cart-01" size={24} />

O componente

Como funciona a nomenclatura HugeIcons

A font é hgi-stroke-rounded com 4.696 ícones gratuitos. CDN: https://cdn.hugeicons.com/font/hgi-stroke-rounded.css

Padrão de nomes
  • Sempre kebab-case (minúsculas com hífens): shopping-cart-01, arrow-down-01
  • Variantes recebem sufixo numérico: -01, -02, -03, -04, -05
  • Alguns ícones existem SEM número (versão base): user, home, check, alert
  • Outros existem SOMENTE com número: home-01, search-01, calendar-03
  • Nomes descritivos compostos: shopping-cart-check-in-01, arrow-data-transfer-vertical
  • NUNCA camelCase, NUNCA PascalCase, NUNCA underscores
Regra de validação OBRIGATÓRIA

NUNCA invente ou adivinhe nomes de ícones. Use SOMENTE nomes desta referência abaixo. Se precisar de um ícone que NÃO está na lista, busque em: https://hugeicons.com/icons?style=Stroke&type=Rounded A URL de cada ícone segue o padrão: hugeicons.com/icon/{nome}-stroke-rounded

Lucide React — Apenas dentro de shadcn/ui

Lucide é usado SOMENTE dentro dos componentes em components/ui/ que vieram do shadcn. Exemplos: accordion.tsx usa ChevronDownIcon, dialog.tsx usa XIcon, etc. 

// ✅ OK — Dentro de components/ui/accordion.tsx (shadcn)
import { ChevronDownIcon } from "lucide-react";

// ❌ PROIBIDO — Em qualquer outro lugar
import { Search } from "lucide-react"; // NÃO FAÇA ISSO

NUNCA faça

  • NUNCA invente nomes de ícone — use SOMENTE a referência acima ou busque em hugeicons.com
  • NUNCA use SVG inline:
  • NUNCA injete CSS de icon font no código (o CSS vem via CDN, não precisa de @font-face local)
  • NUNCA importe de lucide-react fora de components/ui/
  • NUNCA crie ícones com pseudo-elementos CSS (::before, ::after)
  • NUNCA use emoji como ícone em componentes de produção
  • NUNCA use camelCase ou PascalCase em nomes de ícone (é shopping-cart-01, não shoppingCart01)

Exceção única

SVGs de logos de marca (Google, Microsoft, etc.) em app/login/page.tsx são aceitáveis porque não existem como ícones genéricos.

Dica para inverter ícones

Se um ícone aparece espelhado (ex: sidebar-right apontando pro lado errado):

<Icon name="sidebar-right" className="scale-x-[-1]" />

Use scale-x-[-1] via Tailwind para inverter horizontalmente. NUNCA use CSS transform inline.
