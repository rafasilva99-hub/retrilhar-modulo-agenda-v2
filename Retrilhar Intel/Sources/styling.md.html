Styling — Cores, Espaçamentos e Padrões CSS

Cores — Sempre usar classes Tailwind ou CSS variables

O design system define escalas completas em globals.css. Usar assim:

// ✅ CORRETO — Classes Tailwind do design system
className="bg-brand-500 text-brand-50"
className="bg-error-50 text-error-700"
className="bg-success-50 text-success-700"
className="bg-warning-50 text-warning-700"
className="text-slate-500 bg-slate-50"

// ✅ CORRETO — CSS variables quando Tailwind não tem a classe
className="bg-[var(--brand-500)]"
className="border-[var(--border-color-card)]"

// ❌ PROIBIDO — Hex hardcoded
className="bg-[#0B5ED7]"    // Use bg-brand-500
className="text-[#F04438]"  // Use text-error-500
className="bg-[#f5f5f5]"    // Use bg-slate-100 ou var(--border-color-card)

Escala Classe Tailwind Uso

Font Weight

O projeto usa font-weight: 400 para TUDO. Existe um override global:

body .font-semibold, body .font-bold {
  font-weight: 400 !important;
}

NUNCA use font-semibold ou font-bold esperando que fiquem em negrito. Use font-normal sempre.

Espaçamentos

Usar escala Tailwind padrão (base 4px): gap-1 (4px), gap-2 (8px), gap-3 (12px), gap-4 (16px), gap-6 (24px), etc.

Inline styles (style={{}})

PERMITIDO apenas para:

  • Configuração de Chart.js (cores, dimensões de gráficos)
  • Valores dinâmicos calculados em runtime (ex: width: ${percent}%)
  • CSS transforms dinâmicos PROIBIDO para:
  • Cores estáticas
  • Padding, margin, border
  • Font sizes
  • Background colors
  • Qualquer coisa que Tailwind ou CSS variables cubram
