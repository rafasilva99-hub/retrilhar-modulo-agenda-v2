A estrutura é limpa, a linguagem é consistente com o vocabulário do produto (Visão Geral, Participantes, Atualizações, Painel do Dia) e as missões refletem a jornada operacional real — não testes genéricos. É um escopo pronto para ser executado com ajustes pontuais. A seguir, a análise por severidade. 🔴 Críticos (resolver antes de rodar o teste)

  1. Cronograma subestima o tempo real. A soma das missões + abertura + encerramento dá 63 minutos, mas sessões moderadas com think-aloud em 5 missões operacionais densas tipicamente levam 75–90 min. A Missão 3 sozinha (identificar filtros + conferir pagamento + expandir grupo + contratar seguro + check-in individual + check-in em massa + identificar alertas de saúde) é pesada demais para 12 minutos com think-aloud. Recomendo: aumentar Missão 3 para 15 min, ou dividir em 3a (individual) e 3b (grupo + seguro). Total realista: ~75 min.
  2. Missão 3 mistura pagamento com check-in sem justificativa clara. O contexto diz "confira se o pagamento da reserva já foi efetuado", mas o passo esperado depois salta para "confirmar a reserva no card e então contratar o seguro". Há três ações distintas sendo empilhadas (verificar pagamento → confirmar reserva → contratar seguro → check-in) sem que o contexto prepare o participante para isso. Se o pagamento pendente for um bloqueio para o check-in, isso precisa estar explícito no contexto. Se for só observação, deixe como objetivo secundário, não como passo.
  3. Missão 5 não cobre o caso de bloqueio do fechamento do dia. Uma das principais regras de negócio definidas com o Cristiano é que o CTA de encerrar o dia fica travado enquanto houver atividades não concluídas. A missão atual assume que todas já estão concluídas ("verifique se todas as atividades do dia foram concluídas"). Isso testa o caminho feliz, mas não testa a descoberta do bloqueio — que é justamente onde usuários costumam travar. Sugiro: deixar 1 atividade pendente intencionalmente para observar se o usuário entende o toast/progress bar e consegue usar o deep-link para a atividade pendente. 🟡 Moderados (vale ajustar) 4.
