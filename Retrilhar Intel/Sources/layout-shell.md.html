Layout Shell — Regras do Grid System

O layout é 100% controlado por app/(dashboard)/layout.tsx usando CSS Grid. NÃO existe outro arquivo que renderize sidebar, topbar ou tabbar.

Arquitetura

app/(dashboard)/layout.tsx
├── <aside> SidebarMenu       → grid-area: sidebar  (desktop only)
├── <header> TopBar            → grid-area: topbar   (desktop only)
├── <main> {children}          → grid-area: main     (sempre)
└── <nav> MobileTabBar         → grid-area: tabbar   (mobile only)

Grid CSS (definido em globals.css)

Desktop (≥768px):

grid-template-columns: auto 1fr
grid-template-rows: auto 1fr
grid-template-areas: "sidebar topbar" "sidebar main"

Mobile (<768px):

grid-template-columns: 1fr
grid-template-rows: 1fr auto
grid-template-areas: "main" "tabbar"
height: 100dvh (CRÍTICO para tabbar fixa)

Classes CSS do Grid

Classe Função Propriedades críticas
.dashboard-grid Container display: grid; min-height: 100dvh
.grid-area-sidebar Sidebar grid-area: sidebar
.grid-area-topbar TopBar grid-area: topbar
.grid-area-main Conteúdo grid-area: main; overflow-y: auto; min-height: 0
.grid-area-tabbar TabBar grid-area: tabbar; flex-shrink: 0

NUNCA modifique

  • O height: 100dvh e overflow: hidden do grid mobile — mantém tabbar fixa
  • O min-height: 0 do .grid-area-main — permite scroll correto
  • O flex-shrink: 0 do .grid-area-tabbar — mantém altura fixa
  • A visibilidade condicional (hidden md:block) do sidebar e topbar

Navegação

Rotas são mapeadas no layout via objetos menuToRoute, afiliadoMenuToRoute, vendedorMenuToRoute. Para adicionar nova rota:

  1. Criar app/(dashboard)/[nome]/page.tsx
  2. Adicionar entrada no menuToRoute correspondente no layout
  3. Adicionar item no menu do perfil em environments/[perfil]/menu-config.ts

Perfis e menus

Cada perfil tem seu menu definido em environments/[perfil]/menu-config.ts. O sidebar carrega o menu dinamicamente via useProfile(). Perfis: gestor, comercial, operador, guia, financeiro, afiliado, vendedor.
