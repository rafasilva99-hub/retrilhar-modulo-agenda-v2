Análise: Critérios de Filtro e Ordenação no Escopo

O escopo define filtros com razoável granularidade por módulo, mas não especifica ordenação ("ordenar por") em nenhuma tela. A única exceção é o Painel de Reservas, que usa o conceito de "Agrupar por" — não é exatamente ordenação, mas é o mais próximo que o escopo chega disso.

O que foi definido (filtros por módulo)

Central de Vendas / Listagem de Vendas Período, status (pago, pendente, cancelado, reembolsado), canal de venda, produto, vendedor

Carrinhos Abandonados Período, valor mínimo, produto

Extrato de Contas Período, conta, forma de pagamento, canal de venda

Relatórios de Vendas Período, produto, canal, vendedor

Mapa de Vagas Período (7/15/30 dias ou personalizado), status, produto, com vagas/esgotados, guia/responsável

Agenda / Painel de Reservas Data (date picker) + Agrupar por: Venda (responsável), Ordem alfabética, Tipo de tarifa, Item adicional

Agenda / Lista Status (confirmado, pendente), equipe, tipo (saídas, bloqueios)

CRM / Oportunidades Responsável, período, produto

Clientes / Lista Busca por nome/email/documento, período de cadastro, com compras/sem compras

Produtos Categoria, status (ativo/inativo), com estoque/esgotado

Afiliados Período, status

Financeiro / Movimentações Período, tipo (entrada/saída), categoria, conta, centro de custo

Financeiro / Notas Fiscais Período, status (emitida, cancelada), cliente

Assinaturas Produto, ciclo de cobrança, busca por nome/CPF/número, status

O que NÃO foi definido

Nenhuma tela especifica critérios de "Ordenar por" (ex: mais recente, maior valor, nome A–Z)

Não há padrão definido para ordenação padrão das listagens (o que aparece primeiro?)

O template de listagem padrão é mencionado várias vezes, mas não detalha se inclui ordenação

Não há definição de persistência de filtros (o filtro é lembrado entre sessões?)

Não há critério sobre filtros combinados (AND vs OR entre campos)

Conclusão

O escopo está bem coberto em quais campos filtrar, mas tem uma lacuna clara em como ordenar. Isso tende a aparecer como dívida de design quando você for para o UI — especialmente nas listagens com muitos registros (Vendas, Clientes, Movimentações). Vale levantar com o Cristiano se a ordenação é fixada no backend por alguma regra de negócio, ou se precisa ser exposta ao usuário como controle.
